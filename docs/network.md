# Network

## Purpose

Track IP addresses, hostnames, routing, and remote-access details here.

## Current Draft

- Router: local home network gateway
- Proxmox: host machine on wired or wireless LAN
- Ubuntu VM: Docker host reachable through Tailscale
- Laptop: remote admin workstation
